# Проверка тестовой сборки в Windows

Сначала используйте отдельную тестовую учётную запись без ценных файлов на рабочем столе. Скопируйте только `DesktopPrank.exe`. Включите показ Корзины. Не запускайте с правами администратора. Нужен Explorer, не сторонняя оболочка.

Подготовьте текстовые файлы с разным содержимым, папку с вложенным файлом, папку «Новая папка», ярлык, файл с кириллицей и пробелами. Запишите SHA-256 файлов и сделайте снимок расположения значков. Положите ещё один посторонний файл в Корзину до запуска: программа не должна его восстанавливать. Для каждого теста используйте новый набор и журнал конкретного запуска.

| Сценарий | Что проверить | Результат |
|---|---|---|
| `--self-test` | Код выхода 0 | Не проверено |
| Запуск | Никаких окон или подтверждений; появляется рабочий стол, начинается озвучка и уборка | Не проверено |
| Обычная уборка | Реальный drag с удержанием кнопки, прямой путь, небольшие видимые шаги; файлы в Корзине; ввод возвращён | Не проверено |
| Озвучка | Новая реплика обрывает текущую; 4 после первого переноса; 6 только с «Новая папка»; 7 перед папками; 13 и 15 в конце | Не проверено |
| Вмешательство | 3 при первой попытке, 11 повторяется сколько угодно раз при следующих; интервал 6 секунд; реакции прерывают текущую запись даже во время drag | Не проверено |
| Авария во вступлении | Ctrl+Shift+S+P разблокирует ввод; текущий звук прекращается; 16; файлы остаются на месте | Не проверено |
| Авария в середине drag | ЛКМ отпускается; текущий ещё не перенесённый элемент остаётся; все перенесённые файлы и исходные позиции возвращаются | Не проверено |
| Авария после нескольких переносов | Содержимое и имена восстановлены; посторонний элемент Корзины остаётся там | Не проверено |
| Восстановление `--restore` | Файлы и папки на исходных путях; SHA-256 совпадают; повторное восстановление не трогает чужие объекты | Не проверено |
| Конфликт имени | После уборки создать новый файл с исходным именем; восстановление не меняет его; старый остаётся в Корзине; после устранения конфликта повторить | Не проверено |
| Автоупорядочивание выключено/включено | Сравнить позиции до/после восстановления и исходные настройки; при расхождениях должен быть отчёт | Не проверено |
| Привязка к сетке выключена/включена | Аналогично проверить настройки и координаты | Не проверено |
| Маленькие/средние/большие значки | Правильное попадание мышью на исходный значок и в область Корзины | Не проверено |
| Масштаб 100/150/200%, два монитора | Правильные координаты и прямой путь, включая отрицательные координаты | Не проверено |
| Корзина скрыта | Отказ до блокировки и переноса | Не проверено |
| Перенос в Корзину отключён/недоступен | Отмена операции, отсутствие безвозвратного удаления | Не проверено |
| Ошибка доступа/заблокированный файл | Элемент в SKIP до начала уборки, мышь его не трогает; остальные элементы обрабатываются | Не проверено |
| Недоступный вложенный файл | Вся содержащая его папка попадает в SKIP до уборки | Не проверено |
| Изменение доступа после проверки | Элемент пропускается, уборка остальных продолжается | Не проверено |
| 15+ элементов | Реплика 10, отсутствие новых переносов после аварийной комбинации | Не проверено |
| Пустой рабочий стол | Системные значки сохраняются, завершение без ошибок | Не проверено |

Если Explorer не доставляет drop, программа должна остановиться и записать ошибку в отчёт. Если Shell отклоняет перенос и исходный элемент остаётся на месте, он пропускается. При отличающихся координатах сохраните отчёт `.result.txt` и снимки до/после.

Для обратной связи: версия Windows, масштаб и размер значков, настройки упорядочивания, на каком этапе возникла ошибка, текст `.result.txt` и соответствующая строка `.plan.tsv`, работают ли аварийные клавиши. Не отправляйте журнал с личными путями без необходимости.
