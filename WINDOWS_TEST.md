# Проверка текущей сборки в Windows

Для начала подготовьте тестовые файлы, ярлык, папку с вложенным файлом и «Новая папка». Значок Корзины должен быть виден, рабочий стол должен обслуживаться Explorer.

| Сценарий | Ожидаемый результат | Проверено |
|---|---|---|
| Обычный запуск | Нет окон; рабочий стол показывается; звучит только 1, ввод сразу блокируется, движения начинаются после вступления | Нет |
| Вмешательство во вступление | 1 прерывается реакцией, больше не повторяется; после реакции начинаются переносы | Нет |
| Первый перенос | 2 звучит сразу после успешного переноса, а не во вступлении | Нет |
| Реплики по событиям | 4/5 во время подходов, 9 только у ярлыков; 8 периодически, 10 иногда в начале | Нет |
| Фоновая речь | При свободном канале во время уборки звучат комментарии; долгих пустых пауз нет | Нет |
| Уборка | ЛКМ зажата на значке, виден прямой путь к Корзине небольшими шагами, примерно в 2,5 раза быстрее прежнего; переносы реальные | Нет |
| Вмешательство | Сначала 3, затем 11; каждое новое нажатие или щелчок сразу перезапускает реакцию; новое движение после короткой остановки также перезапускает | Нет |
| Папки | 7 возможна при переносе папки; 6 при названии, содержащем «новая папка» без учёта регистра; папки переносятся целиком | Нет |
| Недоступный элемент | В первоначальном списке SKIP, мышь его не трогает | Нет |
| Недоступный вложенный файл | Содержащая его папка пропускается | Нет |
| Доступ изменился после проверки | Элемент пропускается; обрабатываются следующие | Нет |
| Автоупорядочивание | Текущие положения источника и Корзины учитываются между переносами; настройки не меняются | Нет |
| Разные размеры значков и масштаб экрана | Курсор правильно попадает на значки и в Корзину | Нет |
| Завершение | 13 после последнего переноса; затем 15; после полного окончания 15 ввод возвращается и программа закрывается | Нет |
| Ctrl+Shift+S+P | Как аварийная команда не обрабатывается; уборка продолжается | Нет |
| Длительность больше 180 с | Уборка продолжает работать, таймера остановки нет | Нет |
| Ошибка | Ввод освобождается; 16 не запускается | Нет |

Восстановления и возврата позиций в этой версии нет. Для возврата элементов используйте обычную Корзину Windows. Список исходных путей и первоначальных пропусков находится в `cleaner-paths-*.tsv рядом с cleaner.exe`.

При повторном сбое пришлите `cleaner.log` из каталога с `cleaner.exe`. Последние `STAGE` и `ERROR` покажут точный этап и код ошибки. Проверяется сборка с именем `cleaner.exe`; прежний `DesktopPrank.exe` к ней не относится.
