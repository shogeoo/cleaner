# Проверка текущей сборки в Windows

Для начала подготовьте тестовые файлы, ярлык, папку с вложенным файлом и «Новая папка». Значок Корзины должен быть виден, рабочий стол должен обслуживаться Explorer.

| Сценарий | Ожидаемый результат | Проверено |
|---|---|---|
| Обычный запуск | Нет окон; рабочий стол показывается; звучат 1 и 2, а не 16 | Нет |
| Уборка | ЛКМ зажата на значке, виден прямой путь к Корзине небольшими шагами; переносы реальные | Нет |
| Вмешательство | Сначала 3, затем сколько угодно повторов 11 с интервалом 6 с; новая запись обрывает предыдущую | Нет |
| Папки | 7 перед папкой, 6 при «Новая папка»; папки переносятся целиком | Нет |
| Недоступный элемент | В первоначальном списке SKIP, мышь его не трогает | Нет |
| Недоступный вложенный файл | Содержащая его папка пропускается | Нет |
| Доступ изменился после проверки | Элемент пропускается; обрабатываются следующие | Нет |
| Автоупорядочивание | Текущие положения источника и Корзины учитываются между переносами; настройки не меняются | Нет |
| Разные размеры значков и масштаб экрана | Курсор правильно попадает на значки и в Корзину | Нет |
| Завершение | Обработан весь список; ввод возвращается; звучат 13 и 15; программа закрывается без окна | Нет |
| Ctrl+Shift+S+P | Как аварийная команда не обрабатывается; уборка продолжается | Нет |
| Длительность больше 180 с | Уборка продолжает работать, таймера остановки нет | Нет |
| Ошибка | Ввод освобождается; 16 не запускается | Нет |

Восстановления и возврата позиций в этой версии нет. Для возврата элементов используйте обычную Корзину Windows. Список исходных путей и первоначальных пропусков находится в `%LOCALAPPDATA%\DesktopPrank\paths-*.tsv`.
