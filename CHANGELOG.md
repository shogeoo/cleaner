# Changelog

## 0.1.0 — 2026-10-02

- Нативная сборка Windows x64 через MinGW-w64 на Linux.
- Встроенная озвучка с реакциями на события и вмешательство.
- Анимация перетаскивания значков в Корзину с предварительной проверкой доступа.
- Лог и список исходных путей рядом с EXE.

Проверка взаимодействия с Explorer выполняется вручную в Windows.
